Repository ownership

A clear implementation boundary.

AMIS defines what portable memory means. Each consumer owns how its native formats map to that meaning.

AMIS repository

The specification and conformance artifacts.

Normative text, schemas, portable examples, revision and integrity rules, capability and delivery contracts, reference validation tooling, shared conformance vectors and documentation.

Consuming projects

Converters and native integrations.

Native parsers and renderers, provider profiles, golden conversion fixtures, integration tests, source discovery, publication, recovery, synchronization and product interfaces. Each implementation owns its compatibility claims.

Independent ownership. A consumer can implement AMIS in its own language and storage system. The reference validator checks specification artifacts; it does not convert native files, authorize publication or establish native loading.
