AMIS repository

The specification and its documentation.

Normative text, schemas, portable examples, revision and integrity rules, capability and delivery contracts, and documentation. The repository's tooling builds and checks these published pages.

Consuming projects

Validation, converters and integrations.

Validators, canonicalization, native parsers and renderers, provider profiles, golden conversion fixtures, integration tests, source discovery, publication, recovery, synchronization and product interfaces. Each implementation owns its compatibility claims.

Independent ownership. A consumer implements AMIS in its own language and storage system. This repository distributes the specification, schemas, examples and documentation. The guide presents the format and its rules without executing the memory contract.
